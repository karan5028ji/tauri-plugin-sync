Zero-Loop CDC Triggers

SQLite AFTER INSERT/UPDATE/DELETE shadow triggers automatically journal mutations into _sync_changes via json_object(), shielded by a session-level recursion suppressor flag.

guard: (SELECT suppressed FROM _sync_suppress) = 0

Deterministic Consistency

LWW & Tombstones

Deterministic Last-Write-Wins (LWW) utilizing microsecond timestamps. Dedicated _sync_tombstones tracking ensures deleted records are never resurrected by out-of-order remote network packets.

rule: deleted_at >= remote_ts → discard mutation
Zero Rust Boilerplate Required

Integrates in 3 lines of code.

The TypeScript SDK provides a clean, reactive frontend interface while Rust handles heavy serialization and background workers.

src/main.ts
TypeScript / Tauri v2 
import { SyncManager } from 'tauri-plugin-sync';

// 1. Initialize Sync with your local SQLite database
const sync = await SyncManager.init({
  database: 'app.db',
  endpoint: 'https://api.myapp.com/sync',
  tables: ['todos', 'categories', 'notes'],
  authHeader: 'Bearer eyJhbGciOi...',
  syncIntervalMs: 5000, // automatic background polling
  batchSize: 500,       // bounded memory chunking
});

// 2. Reactive status listener for your UI state ('idle' | 'syncing' | 'offline' | 'error')
sync.onStatusChange((status) => {
  console.log('Real-time sync status:', status.state);
});

// 3. Trigger manual sync or let background Tokio loop handle it
await sync.syncNow();
